# System Architecture Diagram Generator & Styler

## 1. What it does
Generates a structured multi-tier system architecture diagram from code and post-processes it into an executive-ready, bordered presentation graphic with branded header and footer metadata.

## 2. Which two libraries, and what each contributes
- **Graphviz (`graphviz`)**: Handles declarative graph definition and topological layout, rendering the multi-tier client/server nodes and directed communication edges into an image.
- **Pillow (`PIL`)**: Performs raster image composition, creating a styled background canvas, calculating margins, drawing the dark navy header banner and footer metadata bar, and applying a multi-pixel framing border around the rendered diagram.

## 3. What someone needs installed before they run it
1. **System Binary (Graphviz engine)**:
   - macOS: `brew install graphviz`
   - Linux: `sudo apt-get install graphviz`
   *(Note: The Python wrapper requires the native `dot` command-line executable on the system PATH).*
2. **Python Packages**:
   ```bash
   pip install -r requirements.txt
   ```
   *(or `pip install pillow graphviz`)*

## 4. The exact command to run it
```bash
python3 v0.3_combined.py
```

## 6. What it can't do yet
- `v0.1_pillow.py` looks for the source GIF at `/Users/vivekdalmia/lec13/ffmpeg/out.gif`. If cloned to a different machine, the input path must be configured.
- It cannot dynamically wrap text or adjust font size responsively if node labels are excessively long.
- It cannot automatically generate dark mode variants or custom color themes without modifying script parameters.
- It requires an external system package (`dot` binary) and cannot run purely self-contained inside a portable Python virtualenv without system-level dependencies.
